# TestCaseForge Premium

Ferramenta profissional para geração automática de casos de teste usando IA, com:

- Login via Google (Supabase)
- Histórico persistente com RLS
- Exportação para Excel (.xlsx)
- Interface moderna com ShadCN UI
- Deploy automático via Vercel

## Tecnologias

- Next.js 14 (App Router)
- Supabase Auth + RLS
- OpenAI API
- ExcelJS
- ShadCN UI
